utils.neutral_mass.add_adduct(name: str, shift: float, sign: int) → None[source]

Validate and add a new custom adduct.

Parameters:

  • name (str) – adduct name. Comparison against existing adducts is case-insensitive, matching the lookup done by adduct().

  • shift (float) – mass shift in Daltons, must be strictly positive.

  • sign (int) – -1 if the adduct is formed by addition to the neutral molecule (shift is subtracted to recover the neutral mass), +1 if formed by loss (shift is added back).

Raises:

ValueError – if name is empty or already used (case-insensitively), sign is not -1/1, or shift is not a strictly positive number.

Example:

>>> # [M+Na]+ is formed by addition of sodium, so sign=-1 (the shift is
>>> # subtracted back to recover the neutral mass from the precursor m/z).
>>> add_adduct("[M+Na]+", shift=22.989221, sign=-1)
>>> list_adducts()
{'[M+Na]+': {'shift': 22.989221, 'sign': -1}}

reset_db.py

Delete all records from BacLipidDB without dropping the tables.

The deletion order respects foreign key constraints:

  1. Annotation (references to Lipid and Detection)

  2. Fragment (reference to Detection)

  3. Detection

  4. Lipid
